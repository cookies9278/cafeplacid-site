Cafe Placid Live Rotator

Cafe Placid Live Rotator is a private automation tool used to manage live broadcasts for the Cafe Placid YouTube channel.

What this application does

The application uses the YouTube Data API to assist with the operation of Cafe Placid live streams, including creating and managing live broadcasts, checking broadcast status, updating broadcast information, and automating scheduled live-stream transitions.

The application is currently intended for personal use by the operator of the Cafe Placid YouTube channel and is not offered as a public service.

Google and YouTube API Access

Access to Google and YouTube account data is requested only when required to operate and manage authorized Cafe Placid YouTube live broadcasts.
